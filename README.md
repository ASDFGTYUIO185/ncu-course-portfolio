## 仓库说明

本仓库用于归档本课程全学期（16 周）的实验内容。每周的实验代码、数据与实验报告均放在对应的 `weekXX` 目录中，提交记录（Commit）会保留每次修改的完整历史，方便复习与验收。

## 使用约定

1. 每周实验结束后，将成果放入当周目录（如 `week03/`）。
2. 每次提交前先用 `git status` 检查改动。
3. 敏感文件（密钥、原始大体积数据）不要提交，`.gitignore` 已做过滤。
