## 目录用途

本目录是第 5 周实验的**独立子模块**，与主仓库其他周次目录互不引用：本周的代码、数据、图表、报告只放在这里，避免与 `week05/`（课程统一归档位）混淆。

## 独立性约定

1. 所有输入输出文件路径均相对于本目录，不跨目录写入。
2. 依赖清单（如后续用到 Python 包）单独记录在 `requirements.txt`。
3. 临时文件、缓存、大图输出交由根目录 `.gitignore` 过滤，不进入提交。
4. 本周成果提交信息统一以 `feat(week05):` 开头，便于历史检索。
